# 콘텐츠 종류별 단건 비교가격 재조사

조사일: 2026-10-15. 한국 소비자에게 표시되는 원화 가격 기준. 앱 구현이 아닌 계산 기준 조사다.

## 조사 결론

모든 시청 기록에 2,200원을 곱하는 방식은 폐기한다. 장르보다 **작품·회차·유통사·시청권 형태**가 단가를 결정한다. 로맨스·스릴러·액션·SF라는 이유만으로 가격을 가감할 근거는 확인하지 못했다.

아래 가격은 넷플릭스의 회당 판매가격이 아니라 다른 합법 서비스의 공개 단건 가격 사례다. 같은 작품을 실제로 대체할 수 있을 때만 절약액이며, 다른 작품의 가격을 적용하면 유사 콘텐츠 환산값이다. 조사 대상이 넷플릭스 한국 광고형에 모두 제공되는지는 확인하지 않았으므로 시청 가능 목록으로 사용하지 않는다. 표본은 시장 전체의 대표 표본이나 평균이 아니다.

## 여러 종류를 섞어 볼 때

```text
C = 결제 주기 실부담액
Pᵢ = i번째 항목의 확인된 단건 가격 또는 선택한 유사 콘텐츠 환산가격
Aᵢ = i번째 항목에서 대안보다 추가로 시청한 광고시간(분)
V = 사용자가 정한 광고 시간 비용(원/시간)

총 단건 환산액 = ΣPᵢ
광고 시간 비용 = V × ΣAᵢ / 60
본전 조건: ΣPᵢ − V × ΣAᵢ / 60 ≥ C
본전 달성률(%) = (ΣPᵢ − V × ΣAᵢ / 60) / C × 100   (C > 0)
```

혼합 시청은 앞으로 볼 종류가 정해져야 추가 화수를 산출할 수 있다. 특정 종류 g를 앞으로 반복해서 볼 때:

```text
잔여액 = max(0, C − 현재까지의 광고 차감 환산액)
추가 필요량 = ceil(잔여액 / (P_g − V × A_g / 60))
```

분모가 양수일 때만 사용한다. 혼합형에서는 모든 종류를 합친 총 화수 하나보다 ‘본전까지 남은 환산액’을 먼저 표시한다.

예: 드라마 2회 × 1,650원 + 애니 3화 × 700원 + 영화 1편 × 2,500원 = 7,900원. 총 6개 항목에서 15초 광고 2개씩 봤다면 광고 총시간은 3분, 시간 비용은 500원이다. 광고 차감 후 환산액은 7,400원으로 7,000원에 도달한다. 모두 유사 작품 단가를 적용했다면 결과 역시 환산 추정치다.

## 구현에 필요한 구분

- 콘텐츠 **형식**(회차형·장편·단편), **장르**(드라마·예능·애니·다큐 등), **권리**(동일 작품 가격 확인·유사 작품 추정·미확인)를 분리한다. 하나의 작품에 장르 태그가 여러 개 붙어도 한 번만 합산한다.
- 작품별 실제 단가 → 확인 가능한 같은 유형의 환산 기본값(사용자 선택) → 미확인 순서로 처리한다. 미확인을 임의의 0원이나 2,200원으로 바꾸지 않는다.
- 현재 CSV의 제목·날짜만으로 장르, 완주, 실제 광고 시간은 확인할 수 없다. 외부 메타데이터 조회 또는 사용자 지정이 필요하며, 시청 기록을 외부에 전송할 경우 기존의 로컬 분석 방침과 함께 설계해야 한다.
- 장르별 광고 CPM을 일괄 지정할 근거도 이번 조사에서 확인하지 못했다. 실제 광고 길이·상품·타겟팅별 단가가 있을 때 광고주 지출 환산액을 따로 계산한다.
