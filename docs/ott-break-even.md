# OTT 본전 계산 기준

조사일: 2026-10-15. 한국 원화 요금 기준. 이 문서는 계산식 설계이며 앱 구현은 포함하지 않는다.

**후속 조사 반영:** 아래 2,200원 고정단가 예시는 MBC 방송 단건 비교에만 사용한다. 전체 콘텐츠의 계산에는 [콘텐츠 종류별 재조사](./ott-content-unit-prices.md)의 작품별 단가 합산 방식을 우선한다. 현재 사용자 요금제는 광고형이며, 실결제액이 확인되지 않은 예시에서는 공개 월 요금 7,000원을 사용한다.

## 1. 본전의 정의와 근거

기본 지표는 **방송을 단건으로 구매하는 비용과 OTT 실결제액의 비교**로 정의한다.

[MBC 공식 이용권 안내](https://www.imbc.com/help/vodnotice/index.html)는 방송 단건 바로보기를 2,200원, 결제 후 24시간 이용으로 안내한다. 프로그램에 따라 가격이 다르다. 따라서 2,200원은 확인 가능한 비교용 기본 단가이며, 모든 OTT 작품의 시장가격이나 평균가격은 아니다.

실제로 같은 작품을 다른 곳에서 구매할 수 있고 구매할 의사가 있을 때만 비용 절감으로 해석한다. 넷플릭스·디즈니+ 독점작 등에 적용한 결과는 **MBC 단건 가격을 대입한 환산값**이다. 다른 구독 서비스나 무료 시청보다 가장 저렴하다는 의미도 아니다.

## 2. 기본 계산식

변수:

- C: 한 결제 주기에 실제로 부담한 OTT 비용(원, C ≥ 0).
- P: 비교하려는 방송 한 화의 단건 구매 가격(원, P > 0). 기본 비교값 2,200원.
- N: 같은 결제 주기에 시청한 비교 대상 화수(정수, N ≥ 0).

```text
필요 화수 = ceil(C / P)
회당 실지출 = C / N                         (N > 0일 때)
단건 구매 환산액 = N × P
본전 달성률(%) = (N × P / C) × 100          (C > 0일 때)
추가 필요 화수 = max(0, ceil(C / P) - N)
환산 차액 = N × P - C
```

ceil은 올림이다. `N × P ≥ C`이면 본전 도달로 판정한다. 비용을 초과해야 한다는 기준을 원하면 필요한 화수는 `floor(C / P) + 1`이다. N=0이면 회당 실지출은 ‘시청 기록 없음’으로, C=0이면 달성률은 ‘추가 부담 없음’으로 표시한다.

예: 넷플릭스 스탠다드 13,500원, P=2,200원일 때 6화의 환산액은 13,200원, 7화는 15,400원이므로 7화에서 도달한다. 5화를 봤다면 환산 달성률 81.5%, 추가 필요 2화, 회당 실지출 2,700원이다.

## 4. 개인 예산과 시청시간으로 확장

단건 구매를 대체하지 않는 시청이라면 사용자가 허용하는 회당 비용 B를 입력한다. 이는 시장가격에 따른 본전과 구분한 **개인 예산 목표**다.

```text
개인 목표 화수 = ceil(C / B)                (B > 0)
```

예: C=13,500원, B=1,000원/화이면 14화. 1,000원은 조사된 평균값이 아니라 사용자가 정한 예산이다.

길이가 다른 콘텐츠를 시간으로 비교하려면 사용자가 정한 시간당 허용 비용 H와 회당 평균 시청시간 T를 사용한다.

```text
목표 시청시간(시간) = C / H                 (H > 0)
목표 화수 = ceil(60 × C / (H × T))          (T > 0, 분/화)
시간당 실지출 = 60 × C / 총 실제 시청분
```

예: C=13,500원, H=2,000원/시간, T=45분/화라면 목표 6.75시간, 9화다. H와 T는 예시 가정이며 조사된 평균이 아니다. 이 목표와 단건 비교 7화는 서로 다른 기준이다.

## 5. 데이터와 결제 처리 원칙

- **결제 주기 일치:** 15일 결제라면 15일부터 다음 결제일 직전까지의 시청과 비용을 비교한다. 달력 월간 집계를 쓸 경우 ‘달력 월 기준 추정’이라고 표시한다. 시청이 없는 기간의 결제액도 포함한다.
- **실부담액:** 실제 적용된 할인·환불과 추가회원 비용을 반영한다. 동시시청 가능 기기 수로 자동 나누지 않는다. 개인 분석이면 실제 개인 부담액과 그 개인 기록을, 가구 분석이면 전체 비용과 전체 기록을 맞춘다.
- **연간 결제:** 연간 본전은 `ceil(연간 실결제액 / P)`다. 디즈니+ 스탠다드 99,000원은 연간 45화. `99,000 / 12 = 8,250원`으로 월평균 목표 4화를 구할 수 있지만 4화 시청만으로 연간 선결제액을 회수한 것은 아니다.
- **단가가 다른 작품:** 에피소드별 실제 단가 Pᵢ를 알면 `ΣPᵢ ≥ C`로 판단한다. 남은 화수를 구하려면 앞으로 볼 작품의 단가 또는 가정 단가가 필요하다.
- **재시청:** 단건 구매로 비교할 때 같은 구매 이용기간 안에서 반복 재생한 회차는 중복 과금하지 않는다. 기간이 지나 재구매가 필요한 경우에만 별도 구매로 센다. 개인 시간 예산에서는 실제 다시 본 시간을 포함할 수 있다.
- **영화:** 방송 한 화로 자동 계산하지 않는다. 영화별 비교 대여료를 입력하면 `방송 환산액 + 영화 환산액 ≥ C`로 확장한다. 가격을 모르면 방송 계산에서 제외한다.
- **CSV 한계:** 이 프로젝트는 `Title`과 `Date`를 읽으며 재생시간·완주율·결제정보가 없다. 제목 기반 시리즈/영화 분류도 추정이다. CSV 행 수를 완주 화수로 단정하지 않고 ‘시청 기록 기준 추정’으로 표시한다. 정확한 시간 계산에는 실제 시청시간 입력이 필요하다.
- **과거 기록:** 2026-10-15에 조사한 현재 요금을 과거 모든 달에 소급 적용하지 않는다. 과거 분석은 당시 실결제액을 입력하거나 ‘현재 요금으로 환산’이라고 표시한다.

## 6. 앱에 적용할 때의 기본값과 문구

초기 설계 예시는 넷플릭스 스탠다드 13,500원, 비교용 방송 단가 2,200원을 사용했다. 후속 조사에서는 사용자 요금제인 광고형의 예시 요금 7,000원과 [콘텐츠별 단가](./ott-content-unit-prices.md)를 사용한다. 실결제액과 비교단가는 사용자가 바꿀 수 있게 하고 먼저 한 결제 주기를 선택한다. 아래 문구는 방송 단건 비교의 예시로만 남긴다.

권장 출력:

> 방송 단건 2,200원 기준, 이번 결제 주기 목표는 7화입니다. 현재 시리즈 시청 기록은 5건이며, 2화가 더 필요합니다. 환산 달성률은 81.5%입니다.

함께 표시할 설명:

> MBC 공식 방송 단건 가격을 비교 기준으로 사용한 추정치입니다. 작품별 가격·실제 시청량에 따라 달라지며, 독점작의 실제 절약액을 뜻하지 않습니다.

## 7. 광고 단가와 광고 시청시간 반영

광고주 지출액, 플랫폼 광고 매출, 이용자의 시간 비용은 별개다. 광고 매출을 이용자가 돌려받는 금액처럼 구독료에서 빼지 않는다.

### 공개 광고 단가

[2025년도 방송시장 경쟁상황 평가, 본문 138쪽 표 3-2-29](https://www.kmcc.go.kr/download.do?fileSeq=70421)은 15초 광고 CPM을 넷플릭스 29,000원, 티빙 20,000원으로 제시한다. 원자료는 각각 2025년 2분기, 2025년 4월 상품 소개서다. CPM은 광고 1,000회 노출당 광고주가 지불하는 금액이므로 1회당 각각 29원, 20원이다. 현재 실거래 단가나 플랫폼 순수익으로 확정할 수는 없다.

실제로 [티빙의 별도 리타겟팅 Beta 상품](https://www.tvingads.com/notices/tving-retargeting)은 논스킵 15초 CPM 16,000원, 논스킵 30초 CPM 32,000원을 안내한다. 상품·길이·타겟팅·프로모션별로 단가를 구분해야 한다.

[넷플릭스 현재 광고 안내](https://help.netflix.com/ko/node/126831)는 시간당 짧은 광고 몇 개가 표시되는 경험으로 설명하며, 모든 작품에 적용할 고정 광고 분량을 보장하지 않는다. 아래의 회당 광고 3분·15초 광고 12개는 계산 예시 가정이며 현재 한국의 실측 평균이 아니다.

### 이용자 본전: 시간 비용을 더하는 방식

추가 변수 A는 한 화를 볼 때의 광고 시청분, V는 사용자가 정한 광고 시청시간의 비용(원/시간)이다. V는 광고주의 CPM과 다르며, 광고 시간에 다른 일을 할 수 있다면 낮게 설정할 수 있다. 비교 대상 단건 VOD에도 광고가 있다면 A는 그 대안보다 더 보게 되는 광고 시간 차이다.

```text
회당 광고 시간 비용 K = A × V / 60
광고 포함 체감 비용 = C + N × K
본전 조건: N × P ≥ C + N × K
광고 시간 반영 필요 화수 = ceil(C / (P − K))
```

마지막 식은 C > 0, P > K일 때 성립한다. C > 0이고 P ≤ K이면 이 기준으로 유한한 화수의 본전에 도달하지 않는다. C=0일 때는 기존의 ‘추가 부담 없음’과 구분해 시간 비용을 평가한다.

넷플릭스 광고형 7,000원, 비교 방송 단가 2,200원, 회당 광고 3분이라는 가정:

| 광고 시간 비용 V | 회당 광고 비용 K | 필요한 화수 |
| --- | ---: | ---: |
| 0원/시간 | 0원 | 4화 |
| 10,000원/시간 | 500원 | 5화 |
| 20,000원/시간 | 1,000원 | 6화 |
| 30,000원/시간 | 1,500원 | 10화 |

### 광고형과 광고 없는 요금제 선택

광고 없는 요금 C_free와 광고형 요금 C_ads의 차액을 D라고 한다. 같은 작품을 같은 품질로 시청한다는 조건에서 광고형이 시간 비용까지 포함해 저렴한 조건은 다음과 같다.

```text
N × K < D
두 요금제 체감 비용이 같아지는 화수 = D / K   (K > 0)
```

넷플릭스 스탠다드 13,500원과 광고형 7,000원은 D=6,500원이다. 회당 광고 3분, V=10,000원이면 K=500원이라 13화에서 같다. 14화부터는 시간 비용을 반영한 광고 없는 요금제가 더 저렴하다. 이는 광고 제거에 대한 판단이며 제공 작품 등 다른 혜택 차이는 별도로 고려한다.

### 광고주 지출 기준의 매출 환산

한 화에서 실제 유료 노출로 집계된 광고가 q개이고 동일 단가 CPM이 적용된다는 가정:

```text
회당 광고주 지출 환산액 R = q × CPM / 1,000
N화의 광고주 지출 환산액 = N × R
광고 환산액이 요금 할인액 D에 도달하는 화수 = ceil(D / R)
```

넷플릭스의 과거 공개 CPM 29,000원, 회당 15초 광고 12개를 가정하면 R=348원이다. 광고형과 스탠다드의 요금 차이 6,500원은 19화의 광고주 지출 환산액 6,612원과 비슷하다. 광고형 월 요금 7,000원 자체와 같은 광고주 지출액은 21화(7,308원)에서 발생한다.

이것은 광고주의 지출액을 단순 환산한 것이며 플랫폼의 순매출·이익, 실제 광고 판매율, 중개 수수료, 세금, 보너스 노출을 반영하지 않는다. 이용자의 현금 절약이나 플랫폼의 손익분기점으로 해석하지 않는다. 광고 길이가 섞이면 `Σ(길이·상품별 유료 노출수 × 해당 CPM / 1,000)`으로 계산한다. CPM을 시간 비용의 대리값으로 쓰는 경우에도 별도 선택 지표로 표시하고 V와 중복 합산하지 않는다.

앱에는 ‘단건 구매 대비 본전’, ‘광고 시간 반영 본전’, ‘광고주 지출 환산액’을 각각 표시한다. CSV에는 광고 노출수·광고 시간이 없으므로 실제 광고량 입력 또는 명시적인 가정이 필요하다.

## 8. 사용자 관찰: 초반에는 드물고 이후 한 편당 광고 2개

사용자의 실제 관찰을 사용할 때 앞 절의 회당 12개 가정을 적용하지 않는다. ‘2개’가 광고 영상 총 2개인지, 여러 영상이 묶인 광고 구간 2번인지 구분한다. 아래는 광고 영상 총 2개 기준이다.

[넷플릭스 2026년 5월 13일 공식 발표](https://about.netflix.com/en/news/netflix-upfront-2026-get-closer)는 시청 행동에 따라 광고량과 빈도 제한을 동적으로 조정하는 개인화 기능을 테스트 중이라고 밝혔다. 그러나 한국의 해당 계정이 테스트 대상인지, 가입 후 시간이 지나면 또는 연속 시청 후 반드시 광고를 늘리는 정책인지까지는 확인되지 않는다. 사용자 관찰은 개인 데이터로 반영하며 보편적 증가 규칙으로 일반화하지 않는다.

한 화당 실제 광고 개수를 qᵢ, 실제 광고 총시간을 Aᵢ(분)로 기록하면:

```text
N화 광고주 지출 환산액 = Σ(qᵢ × CPMᵢ / 1,000)
N화 광고 시간 비용 = V × ΣAᵢ / 60
광고 시간 반영 본전 조건 = N × P ≥ C + V × ΣAᵢ / 60
```

첫 식은 각 화에 동일 상품·길이의 광고만 있다는 조건이다. 혼합이면 개별 광고 단위로 합산한다. 시간과 단가가 달라지므로 고정 평균을 넣은 필요 화수 공식보다 누적 조건을 우선한다.

- 15초 광고 2개: 과거 공개 CPM 29,000원을 적용한 회당 광고주 지출 환산액은 58원이다. 6,500원 요금 할인액에 해당하는 광고주 지출은 이 노출량이 계속될 경우 113화에서 발생한다. 초반 광고를 포함한 실제 누적 노출수로 계산해야 하며 플랫폼의 순이익은 아니다.
- 15초 광고 2개는 총 30초다. V=10,000원/시간이면 회당 시간 비용은 약 83.33원이고, C=7,000원, P=2,200원일 때 필요 화수는 `ceil(7,000 / (2,200 − 83.33…)) = 4화`다.
- 30초 광고 2개는 총 1분이다. 같은 V라면 약 166.67원이고, 필요 화수는 4화다. 15초 CPM을 30초 광고에 그대로 적용해 매출을 추정하지 않는다.
- 초반 B화를 완전히 광고 없이 보고 이후 15초 광고 2개씩 본다는 단순 모형에서는 누적 광고주 지출 환산액이 `58 × max(0, N − B)`다. 할인액 6,500원에 도달하는 총 시청 화수는 `B + 113`이다. 실제 사용자는 초반에도 광고가 드물게 있었다고 했으므로 이 모형의 B는 예시 변수이며 확인된 무광고 구간이 아니다.
