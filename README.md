# 넷플릭스 시청 통계 뷰어

넷플릭스에서 내려받은 `NetflixViewingHistory.csv` 를 **브라우저 안에서만** 분석해 보여주는 정적 웹앱입니다.
서버가 없고, 파일은 어디에도 업로드되지 않습니다.

React + TypeScript + Vite로 만들었습니다. CSV 파싱·날짜 해석·차트는 직접 구현했고,
공유 이미지 생성에는 `html-to-image`를 사용합니다.

화면은 Awwwards의 에디토리얼 레이아웃에서 대형 타이포·넓은 여백·모듈형 카드 구성을 참고하고,
Netflix의 블랙·레드 색상과 시네마틱 그라데이션을 결합했습니다. 외부 이미지와 웹폰트는 사용하지 않습니다.

## 빠르게 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | `dist/` 로 정적 빌드 (어떤 정적 호스팅에도 그대로 올릴 수 있습니다) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run lint` | ESLint |
| `npm run typecheck` | 타입 검사 |
| `npm test` | 파서·통계 로직 테스트 (Vitest) |

## 사용법

1. 넷플릭스 웹에서 분석할 **프로필**로 전환합니다.
2. **계정** → **프로필** → **시청 기록**으로 이동합니다. 로그인되어 있다면 [시청 기록 페이지](https://www.netflix.com/viewingactivity)로 바로 열 수도 있습니다.
3. 기록 아래의 **더 보기**를 누른 뒤 **모두 다운로드**를 선택합니다. 선택한 프로필의 `NetflixViewingHistory.csv`가 내려받아집니다.
4. 받은 `NetflixViewingHistory.csv` 를 앱 화면에 끌어다 놓거나 **파일 선택** 으로 불러옵니다.
5. 바로 통계가 나옵니다. 넷플릭스 계정이 없어도 **샘플 데이터로 둘러보기** 로 화면을 확인할 수 있습니다.

### 보여주는 것

- **당신은 넷플릭스로 본전을 뽑으셨나요?** — 콘텐츠별 단가, 실제 요금, 가족·친구와의 비용 분담을 반영한 본전 분석
- 결제 주기별 최초 본전 도달일·미달 금액과 **본전 뽑은 달 / 못 뽑은 달** 모아 보기
- 작품별 콘텐츠 유형·단가 수정, 광고 시간 비용, 초반 무광고 구간, 구독하지 않은 주기 제외
- 총 시청 항목 수, 시청한 날 수, 첫 시청일부터 마지막 시청일까지의 기간, 하루 평균 시청량
- 가장 많이 본 작품, 최장 연속 시청일, 하루 최다 시청 기록
- 월별 시청 건수 · 요일별 시청 습관 · 시간에 따른 누적 시청량
- 작품명을 노출하지 않고 날짜·편수만 보여 주는 일별 시청 잔디와 연속 시청 기록
- 연도별 시청 기록을 5장으로 정리한 **한 해 돌아보기**: 전체 시청량, 최애 작품, 시청 습관, 35일 스트릭 달력, 공유 카드
- 인스타그램 스토리처럼 버튼·방향키·터치 스와이프로 넘기는 9:16 돌아보기 화면
- 현재 장만 저장하거나 5장 모두를 각각 인스타그램 스토리 규격인 **1080×1920 PNG**로 기기에 저장
- 시리즈 / 영화 추정 분류와 작품별 에피소드 집계
- 작품·에피소드 검색, 날짜 범위 필터, 종류 필터
- 정렬 가능한 작품별 집계표와 상세 시청 기록표

### 본전 분석 사용법

1. CSV를 불러온 뒤 **내가 실제로 내는 요금**에서 요금제와 실제 월 결제액을 확인합니다. 할인·제휴 요금은 직접 수정할 수 있습니다.
2. 함께 비용을 분담하는 가족·친구 수를 **본인 제외**로 입력합니다. 내 부담액은 `(월 결제액 + 별도 추가 비용) / (본인 포함 분담 인원)`입니다. 불균등하게 나눈다면 **내 부담액 직접 입력**을 선택하세요. 이 프로필 한 사람의 기록만 개인 부담액과 비교합니다.
3. 결제일과 분석 기간을 확인합니다. 해당 기간과 겹치는 결제 주기마다 월 요금 전액을 반영합니다. 기록이 없는 달도 구독했다고 가정하며 **결제 주기별 내역**에서 실제 구독하지 않은 주기를 제외할 수 있습니다. 현재 입력한 요금·분담 인원은 선택 기간 전체에 동일하게 적용합니다.
4. **콘텐츠마다 다른 단가**에서 작품별 유형을 지정합니다. CSV에는 장르가 없어 시리즈는 ‘회차형 · 유형 미지정’ 1,650원, 영화는 1,500원으로 우선 추정합니다. 애니메이션 700원, 유아 교육 500원, 장편 다큐 2,500원 등 유형별 기본값과 작품별 단가를 바꿀 수 있습니다. 독점작은 직접 단가를 지정하거나 ‘미확인 · 계산 제외’를 선택하세요.
5. 광고 시간까지 고려하려면 **광고 시청시간도 비용에 반영하기**를 엽니다. 기본 예시는 한 편당 15초 광고 2개, 시간당 10,000원이며, 실제 관측값이 아닌 수정 가능한 가정입니다. 분석 기간 초반 무광고 건수는 매달 초기화되지 않습니다. 작품별 광고 수도 수정할 수 있습니다. 키즈 프로필은 광고 시간 0으로 계산합니다.
6. **이번 결제 주기의 본전은?**에서 주기를 선택해 최초 도달일을 확인합니다. **앞으로 이 종류만 본다면?**에서는 남은 금액을 채울 예상 편수를 볼 수 있습니다.
7. **본전 뽑은 달, 못 뽑은 달**에서 결제 주기를 달 단위로 모아 봅니다. 뽑은 달·못 뽑은 달만 걸러 볼 수 있고, 달을 누르면 위의 결제 주기 결과가 그 달로 바뀝니다.

계산 기준:

- **결제 주기 본전:** `주기 내 콘텐츠 단건 가격 합계 − 광고 시간 비용 ≥ 내 결제 주기 부담액`. 최초 도달일은 처음 이 조건을 만족한 날입니다. 이후 광고 비용으로 누적액이 내려가면 현재 상태는 다시 미달이 될 수 있습니다.
- 비용이 0원이면 ‘부담 없음’으로 표시하며 달성률이나 본전 달성일을 꾸며내지 않습니다. 같은 날짜·제목 중복행은 한 건만 계산하고, 날짜가 다른 재시청 기록은 별도 건으로 셉니다.

단가는 2026-10-15 확인한 다른 합법 서비스의 바로보기·대여 사례 중 유형마다 낮은 값을 고른 **환산 추정치**이며, 시장 평균·최저가·실제 지출액이 아닙니다. 화면의 유형별 단가 칸마다 근거 사례 링크를 달았고, 결과에는 환산액 중 유형별 추정 단가가 차지하는 비율을 함께 표시합니다. 같은 작품을 실제로 단건 구매하는 것을 대체할 때만 절약액으로 해석할 수 있습니다. CSV에는 완주 여부·시청시간·광고 정보가 없으며, 누락된 기록도 알 수 없습니다. 분류·단가와 구독 기간을 확인한 뒤 결과를 읽어 주세요.

조사 근거: [콘텐츠 종류별 가격](docs/ott-content-unit-prices.md), [본전·광고 계산식](docs/ott-break-even.md). 설정과 작품별 수정값도 메모리에서만 유지되며 새 파일을 불러오거나 새로고침하면 초기화됩니다. 본전 분석은 기존 통계 검색·종류·날짜 필터와 독립적으로 계산합니다.

## 개인정보 보호

- **전송 없음** — 파일은 `File.text()` 로 읽어 메모리에서만 처리합니다. 분석 과정에 네트워크 요청이 전혀 없습니다.
- **저장 없음** — localStorage, IndexedDB, 쿠키를 쓰지 않습니다. 새로고침하면 데이터는 사라집니다.
- **추적 없음** — 애널리틱스, 외부 폰트, 외부 스크립트, CDN 호출이 없습니다. 빌드 결과물은 HTML/CSS/JS 뿐입니다.
- **기기 안에서 이미지 생성** — 한 해 돌아보기 PNG도 브라우저에서 만들며 서버로 전송하지 않습니다. 이미지에는 시청 취향이 담기므로 공유 전 내용을 확인하세요.
- 기기에서 확인하려면 개발자 도구 네트워크 탭을 열어둔 채로 파일을 올려보세요. 요청이 잡히지 않습니다.

`data/` 폴더는 개인 CSV 를 로컬에서 시험해 보라고 둔 자리이며 `.gitignore` 로 Git 추적에서 제외되어 있습니다.
저장소에 포함된 `public/sample-viewing-history.csv` 는 전부 **가상의 작품명**으로 만든 예시 파일입니다.

## CSV 처리 방식

`Title`, `Date` 두 열만 있으면 됩니다. 실제 내보내기 파일이 제각각이라 아래를 견고하게 처리합니다.

- **CSV 구조** — RFC 4180 방식으로 직접 파싱합니다. 따옴표 안의 쉼표(`"심야의 서울: 시즌 1: 첫 번째 밤"`),
  이스케이프된 따옴표(`""`), 필드 안 줄바꿈, CRLF, BOM, 빈 줄을 처리합니다. 구분자는 `,` `;` 탭 중에서 자동 추정합니다.
- **열 찾기** — `Title`/`Date` 외에 `제목`/`날짜`/`시청일` 같은 한글 헤더도 인식하고, 열 순서가 바뀌어도 찾아냅니다.
  헤더 줄이 없는 파일은 2열 구조로 간주해 읽습니다.
- **날짜 형식** — `9/3/26`, `2026-09-03`, `2026. 9. 3.`, `2026년 9월 3일`, `03.09.2026`, `3 Sep 2026`, `Sep 3, 2026`.
  `M/D/Y` 와 `D/M/Y` 는 열 전체를 훑어 판별하며(첫 자리에 12 초과 값이 있으면 일이 앞), 개별 값에서 판별되면 그쪽을 따릅니다.
  두 자리 연도는 69 이하를 2000년대로 봅니다. `2/30` 처럼 존재하지 않는 날짜는 거절합니다.
- **깨진 행** — 파일 전체를 실패시키지 않고 해당 행만 건너뛴 뒤, 줄 번호와 이유를 화면에 알려줍니다.

## 시리즈 / 영화 추정 규칙

넷플릭스 CSV 에는 작품 종류가 없어서 제목 표기로 추정합니다. 위에서부터 먼저 맞는 규칙을 씁니다.

1. `시즌 2`, `2기`, `파트 1`, `리미티드 시리즈`, `Season 1`, `Limited Series` 같은 조각이 있으면 **시리즈**.
   그 앞이 작품명, 뒤가 에피소드명입니다.
2. 마지막 조각이 `12화`, `제3화`, `Episode 4` 면 **시리즈**.
3. `작품명: 부제` 꼴이면서, 같은 작품명 아래 서로 다른 부제가 **3개 이상** 모였으면 **시리즈**.
4. 그 외는 **영화**.

3번 규칙 때문에 한 화만 본 시리즈는 영화로 잡히고, 부제가 붙은 극장판이 여러 편 있으면 시리즈로 잡힐 수 있습니다.
추정값이라는 점을 화면에도 표시해 두었습니다. 규칙은 `src/lib/stats.ts` 상단에 모아 두었습니다.
